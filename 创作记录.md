# 桐崎千棘回收站桌宠

新形象使用内置 image_gen 生成，保留透明背景。原始动画未修改。

参考图 1：现有「小缎带 / 桐崎千棘」Q 版人物。
参考图 2：用户提供的咬手帕、含泪生气表情。

提示词：

Create ONE full-body transparent sprite for a Windows desktop pet. Image 1 is the exact existing chibi character identity and drawing style to preserve: golden long ponytail with red bow, blue-white sailor blouse, orange necktie, blue pleated skirt, dark knee socks, brown loafers, compact chibi proportions. Image 2 is ONLY the reference for the NEW expression and gesture: comically angry and tearful, sharp scrunched white anime eyes with tears at corners, biting the middle of a pale pink handkerchief while BOTH clenched hands pull its two lower corners, elbows bent. Match that iconic handkerchief-biting pose. Keep Image 1 full-body chibi proportions, same outfit and hair, frontal standing pose, feet on same baseline, both shoes fully visible. Crisp clean anime sticker outline and flat colors matching Image 1. The handkerchief must be visibly held between mouth and both hands. This is the hover reaction when a file is dragged onto her. No scenery, speed lines, captions, text, shadows, floating symbols or additional characters. Exactly one centered character on actual transparent background with clear margins. Do not include the square background of Image 2.

Windows 接口依据：[SetOperationFlags](https://learn.microsoft.com/en-us/windows/win32/api/shobjidl_core/nf-shobjidl_core-ifileoperation-setoperationflags)、[PreDeleteItem](https://learn.microsoft.com/en-us/windows/win32/api/shobjidl_core/nf-shobjidl_core-ifileoperationprogresssink-predeleteitem)。回收前检查 TSF_DELETE_RECYCLE_IF_POSSIBLE；接口检查方式也可见 [Electron 的实现](https://github.com/electron/electron/blob/main/shell/common/platform_util_win.cc)。

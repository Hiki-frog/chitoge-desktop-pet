桐崎千棘 · 回收站桌宠  v1.0

启动
双击同文件夹内的 Chitoge.exe。请保留 assets 文件夹。
这是独立 Windows 桌宠，不是 ChatGPT Pets 内部的功能升级。
原来的 ChatGPT 桌宠仍可使用；若想屏幕上只出现一个，可以在原应用里隐藏它。
无需安装、无需登录，不联网，不设置开机自启。适用于 Windows 10 / 11 x64，使用系统 .NET Framework 4.x。

操作
• 左键按住她拖动：移动位置。
• 双击：挥手。
• 把文件或文件夹拖到她身上：变成咬手帕、含泪生气的形象。
• 拖离她：恢复日常形象。
• 松开：列出文件，点击“移入回收站”才执行；“先留着”或 Esc 取消。
• 右键：打开系统回收站、预览新表情、播放全部原有动作、切换视线跟随、调整大小、退出。
• Ctrl + Alt + P：找回桌宠（若该快捷键被其他软件占用，请使用托盘菜单）。
• 从系统托盘也能找回桌宠、打开回收站或退出。

保留的内容
原始精灵图逐字节保留：9 组动作、16 个视线方向，共 73 帧。
待机、向右跑、向左跑、挥手、跳跃、委屈、等待、思考、检查均可从右键菜单播放。
日常播放待机与偶尔挥手，视线跟随鼠标。新咬手帕状态是独立透明图像，带轻微抖动。

回收行为
使用 Windows IFileOperation 系统回收站接口。确认前不会移动文件。
程序检查每项操作的回收标志；不能回收时停止，不使用永久删除作为替代。
多个文件可能部分成功，遇到问题会给出已完成项数；可到系统回收站核对并还原。
不提供“清空回收站”或“永久删除”按钮。
本版接收本机固定磁盘的普通文件和文件夹。
暂不接收网络路径、移动设备、链接/重定向目录、云端占位文件、磁盘根目录、系统目录、程序自身及整个个人目录。
普通 .lnk 快捷方式只回收快捷方式文件，不回收其目标。
请用普通权限启动；从更高权限运行的程序拖入文件可能受 Windows 权限隔离限制。

本机验证情况
已编译并实际启动；已检查中文界面、右键菜单、桌宠位置拖动和原有素材加载。
自动检查通过：73 帧读取、拖入变脸、拖离恢复、取消后保留文件、非文件拖入拒绝、重复路径去重、父子项目合并、不允许路径拦截、非回收删除拦截。
隔离测试账户无法使用自己的系统回收站；程序已停止且测试文件完整保留。
因此尚未确认当前用户环境中的成功回收与还原；首次使用请用一个新建的无用测试文件试用。
自动化工具不支持跨窗口拖放，完整的真实文件拖入流程仍需在正常桌面中试用。
